#Passo

Preferências

Guia rápido de funções (legendas iguais ao modelo de referência)

Financeiro (TVM) — linha 1
n·i·PV·PMT·FV
Digite um valor e pressione a tecla p/ guardá-lo; pressione sem digitar nada para calcular essa variável a partir das outras 4.
f n → AMORT
Amortização do período atual.
g n → 12×
Multiplica X por 12 (ex.: anos → meses).
f i → INT
Converte a taxa periódica de X para a taxa efetiva anual.
g i → 12÷
Divide X por 12 (ex.: taxa anual → mensal).
f PV → NPV
Valor presente líquido dos fluxos de caixa, usando a taxa em X.
g PV → CFo
Define o fluxo de caixa inicial (investimento) = X.
f PMT → RND
Arredonda X para as casas decimais atuais.
g PMT → CFj
Adiciona X como um fluxo de caixa periódico.
f FV → IRR
Taxa interna de retorno dos fluxos de caixa.
g FV → Nj
Define quantas vezes o último CFj se repete.
g CHS → DATE
Soma X dias à data de hoje e mostra o resultado.
g 7 → BEG / g 8 → END
Pagamentos antecipados / postecipados.
g 9 → MEM
Mostra a soma de todos os registradores de memória.
Matemática & depreciação — linha 2
yˣ · 1/x
Potenciação e inverso.
f yˣ / f 1/x → PRICE / YTM
Cálculo de títulos (bond) — não incluído nesta versão.
g yˣ → √x / g 1/x → eˣ
Raiz quadrada e exponencial.
%T · Δ% · %
Percentual do total, variação percentual e percentual simples.
f %T → SL / f Δ% → SOYD / f % → DB
Depreciação (linear, soma-dos-dígitos, saldo decrescente) do 1º ano — Y=custo, X=valor residual, n=vida útil.
g %T → LN / g Δ% → FRAC / g % → INTG
Log. natural, parte fracionária e parte inteira de X.
g EEX → ΔDYS
Abre a aba Datas para calcular dias entre datas.
g 4 → D.MY / g 5 → M.DY
Formato de exibição de data.
g 6 → x̄ʷ
Média ponderada dos dados estatísticos.
Controle, pilha & memória — linha 3
R/S
Roda o programa gravado do início ao fim.
f R/S → P/R
Alterna entre gravar (PROGRAM) e executar (RUN).
g R/S → PSE
Pausa (indicação visual no visor).
SST
Executa o próximo passo gravado, um de cada vez.
f SST → Σ
Acumula X,Y nos somatórios estatísticos (mesmo que Σ+).
g SST → BST
Volta um passo no programa.
R↓
Rotaciona a pilha (X→T→Z→Y→X).
f R↓ → PRGM
Abre a aba Programa.
g R↓ → GTO
Volta o programa para o passo 1.
x⇄y
Troca X e Y.
f x⇄y → FIN
Limpa os registradores financeiros (n, i, PV, PMT, FV).
g x⇄y → x≤y
Testa se X≤Y e mostra Verdadeiro/Falso.
CLx
Limpa apenas X.
f CLx → REG
Zera os 10 registradores de memória (STO/RCL).
g CLx → x=0
Testa se X=0 e mostra Verdadeiro/Falso.
ENTER
Duplica X em Y (empilha).
f ENTER → PREFIX
Cancela um STO/RCL pendente.
g ENTER → LSTx
Recupera o X anterior à última operação.
ON · f · g · STO · RCL · Σ+ — linha 4
ON
Liga/desliga — os dados ficam guardados mesmo desligada (memória contínua).
STO / RCL
Aperte e depois um dígito de 0 a 9 para guardar/recuperar nesse registrador.
g 0 → x̄
Média de X.
g , → s
Desvio padrão amostral.
Σ+
Acumula o par (Y,X) nos somatórios estatísticos.
g Σ+ → Σ−
Remove o último par acumulado.
